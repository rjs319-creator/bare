# Verification reports

Dated, in-session verification runs. Each file is the record of one live-market check of a
system that had, until then, only been exercised outside market hours.

These are written by scheduled agents following a runbook in `docs/` (see
`LOWFLOAT-INSESSION-VERIFY.md`) and land here via a PR — the PR is what notifies a human,
since nobody is watching the run itself. The title carries the verdict so it reads from an
email subject line.
